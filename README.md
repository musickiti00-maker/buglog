# Bugnity 버그니티 🐞

곤충과학자를 꿈꾸는 학생의 곤충 관찰 기록장.

## 기록 추가하는 법 (컴퓨터 지식 없어도 OK)

1. 사이트 맨 아래 **기록 만들기 도우미**에서 칸을 채우고 **글 만들기** → **복사하기**
2. GitHub에서 이 저장소의 `data.js` 파일을 열고 연필(✏️ Edit) 버튼 클릭
3. `const LOGS = [` 바로 아래 줄에 붙여 넣기
4. 오른쪽 위 **Commit changes** 클릭 → 1~2분 뒤 사이트에 자동 반영

## 사진 올리는 법

1. GitHub에서 `photos` 폴더 → **Add file → Upload files** 로 사진 올리기
2. 기록의 `photo` 칸에 `photos/파일이름.jpg` 적기

## 안전 규칙

- 실명 · 학교 이름 · 집 주소 · 정확한 장소는 쓰지 않아요 (장소는 "동네 공원"처럼 넓게)
- 얼굴이 나온 사진은 올리지 않아요
